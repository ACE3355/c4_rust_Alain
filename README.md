# c4_rust_Alain

## Overview
A Rust implementation of the C4 compiler/interpreter. This project replicates the functionality of the original C4 written in C, using a single-file Rust implementation.
if anyone wants to run the code and check

step 1 : git clone https://github.com/ACE3355/c4_rust_Alain.git

step 2: cd c4_rust_Alain

step 3: cargo build

this below is only for test cases
step 4: cargo test

if separate file needed to check  then run the below command

step 5: cargo run -- src/test.c
(please check that the path is correct)
